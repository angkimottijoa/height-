Jewel Changi · Diagrid  (Minecraft Bedrock 애드온)
================================================
크기 : 171 x 46 x 228 블록 (높이 45 + 최상단 철골 1)
블록 : 철 블록 25,439 / 청록색 스테인드글라스 53,332  = 78,771
격자 : 부재 96개 x 2방향, 다이아몬드 한 칸 약 12.8 블록

[적용]
 1. JewelDiagrid.mcaddon 실행 -> 마인크래프트가 자동 임포트
 2. 월드 설정 > 동작 팩에서 "Jewel Changi · Diagrid" 활성화 + 치트 켜기

[생성]  서 있는 자리가 -X/-Z 모서리, +X/+Z 방향으로 지어집니다.
   /function diagrid/build            <- 전체 한 번에
   /function diagrid/p01 ~ p12        <- 렉 걸리면 12타일로 분할
   /function diagrid/clear            <- 자리 비우기 (지형 삭제, 되돌리기 불가)

 구조물 블록 수동 배치도 가능: 이름칸에 diagrid:a1 ~ diagrid:c4

[특징]
 - 빈 공간은 structure void 라 주변 지형을 지우지 않습니다.
 - 철골은 유리면에서 1칸 띄워 얹혀 있어 아래로 청록 유리가 비칩니다.
 - 필요 재료: 철괴 228,951 / 유리 53,332 / 청록염료 약 6,700
