# 아르세온 DLC (8Crafter's Server Utilities 확장)

`dist/ArceonDLC.mcaddon` — 행동 팩 1개(리소스 팩 없음). MCBE **1.26.40 이상**.

Java 플러그인 **Arceon 0.5.6**(Arcaniax)의 건축 도구를 뜯어서 베드락 스크립트로 옮긴 애드온입니다.
서버에 이미 들어가 있는 **8Crafter's Server Utilities & Debug Sticks**와 같이 쓰는 확장(DLC)으로 만들었고,
그 팩의 선택 도구로 찍은 pos1/pos2를 그대로 따라옵니다. 8Crafter 팩이 없어도 단독으로 동작합니다.

그림자(Shadow)·로프(Rope)·실험적 도구(Wax, FixConnect, WFC)는 요청대로 넣지 않았습니다.

## 시작하기

1. 월드(서버)에 `ArceonDLC.mcaddon`의 행동 팩을 추가합니다. 실험적 기능은 필요 없습니다.
2. 관리자(OP)이거나 `arceon` 태그가 있어야 합니다. (`/tag <이름> add arceon`)
3. `/arc:tools` 로 **도구 아이템 6개**를 받습니다.

| 명령어 | 내용 |
|---|---|
| `/arc:tools` | 도구 아이템 6개 받기 |
| `/arc:menu` | 전체 메뉴 |
| `/arc:wand` | 선택 지팡이만 받기 |
| `/arc:undo` / `/arc:redo` | 되돌리기 / 다시 하기 (플레이어마다 15번) |

## 도구 아이템 (모바일 기준 조작)

**터치** = 블록을 가볍게 톡 (PC: 우클릭), **부수기** = 꾹 눌러 부수기 (PC: 좌클릭).
도구를 들고 **웅크리고 터치**하면 그 도구의 메뉴가 열립니다. 도구로 블록을 부숴도 블록은 부서지지 않습니다.

| 아이템 | 터치 | 부수기 | 웅크리고 부수기 |
|---|---|---|---|
| **선택 지팡이** (블레이즈 막대) — 영역 모드 (기본) | 1번 지점 | 2번 지점 | **곡선 점 모드 켜기** |
| **선택 지팡이** — 곡선 점 모드 (켜짐) | 곡선 점 추가 | 마지막 점 취소 | **곡선 점 모드 끄기** (영역 모드로) |
| **프레임 피커** (자수정 조각) | 지금 프레임에 점 추가 | 마지막 점 취소 | **프레임 저장** (다음 점부터 새 프레임) |
| **블록 피커** (망원경) | 그 블록 저장 (방향 등 상태 포함) | 마지막 블록 빼기 | |
| **클립보드 도구** (종이) | 붙여넣기 | 선택 영역 복사 | 90° 회전 |
| **에셋 도구** (메아리 조각) | 고른 에셋 놓기 | 선택 영역을 에셋으로 저장 | |
| **지형 도구** (빈 지도) | 지형 메뉴 (지형 생성, 눈 덮기) | | |

- 터치는 블록을 바라보기만 해도 300칸 멀리까지 됩니다.
- 선택 지팡이 메뉴(웅크리고 터치)에 곡선 도구·모양 만들기·변형·채우기·글자 쓰기·브러시·설정이 있고, 맨 위 버튼으로도 곡선 점 모드를 켜고 끕니다.
- 지금 어느 모드인지 터치할 때마다 화면 위에 `[영역]` / `[곡선 점]`으로 표시됩니다.
- 영역과 곡선 점은 **따로 저장**됩니다. 곡선 점 모드에서 부수기(마지막 점 취소)를 해도 영역은 그대로입니다.
- 꾹 누르고 있어도 **한 번만** 처리됩니다(손을 뗐다가 다시 눌러야 다음 동작).
- 모바일에서 꾹 누르면 처음에 터치가 먼저 들어오는데, 같은 블록에서 곧바로 부수기로 이어지면 그 터치는 **없던 일로** 하고 부수기만 처리합니다(마지막 점 취소가 정확히 한 점만 지움, 영역 1번이 같이 찍히지 않음).
- 도구를 들고 있으면 입자로 보입니다: 영역 테두리(엔드 막대), 곡선 점(초록)과 곡선(불꽃), 프레임(파란 불꽃, 그리는 중인 프레임은 초록)과 **프레임끼리 이어지는 레일**(불꽃 — 채울 때와 같은 계산이라 이대로 이어짐),
  클립보드는 **바라보는 곳에 붙여넣으면 차지할 영역**을 불꽃 테두리로 보여 줍니다.
- **8Crafter 선택 도구**로 찍은 1번·2번 지점도 자동으로 따라옵니다. (그 팩의 저장값은 다른 팩이 읽을 수 없어서,
  선택 도구를 쓸 때마다 같은 방식으로 따라 기록합니다. 8Crafter의 `\pos1` 같은 명령어로 지정한 값은 따라오지 않습니다.)
- 곡선 점 모드와 영역 모드는 완전히 따로입니다. 곡선 점 모드에서는 곡선 점만 찍히고 입자도 곡선 점만 보이며, 곡선 도구는 곡선 점만 씁니다(영역 1번·2번은 쓰지 않음).

### 프레임 피커 — 곡면 채우기 / 면 채우기

프레임은 도형 하나(점 여러 개)입니다. 점을 터치로 찍고, 웅크리고 부수기로 저장하면 다음 점부터 새 프레임이 됩니다.
웅크리고 터치 > **채우는 방식 바꾸기**로 둘 중 하나를 고르고 **실행**합니다.

- **곡면 채우기** (아르세온 로프트): 프레임과 프레임 사이를 매끄러운 곡면으로 잇습니다. 프레임이 1개면 그 도형을 평면으로 채웁니다.
- **면 채우기**: 평평한 면으로 채웁니다. 프레임 1개 = 도형 안 채우기(오목한 도형도 됨), 여러 개 = 프레임 사이를 평면으로 잇기.
  처음·마지막 프레임 막기, 끝 점과 첫 점도 잇기(통 모양), 테두리 선만 옵션.

### 블록 피커

블록 피커로 블록을 터치하면 그 블록이 **상태 그대로** 저장됩니다(최대 27개). 모든 도구의 블록 입력에서
"블록 피커로 고른 블록"이 기본으로 선택되어 바로 씁니다. 웅크리고 터치하면 목록이 나오고, 켠 블록만 섞어 쓰거나
팔레트로 저장하거나 목록을 비울 수 있습니다(하나도 안 켜면 전부 섞어 씀).

### 클립보드

- 클립보드 도구로 **부수기** = 선택 영역 복사. **자유 회전**과 **크기 조절**에서 "월드는 그대로 두고 결과만 클립보드에 저장"을 켜면
  돌리거나 키운 결과가 클립보드로 들어옵니다(원본은 그대로).
- 클립보드 도구를 들면 바라보는 곳에 놓일 자리가 테두리로 보이고, **터치**하면 터치한 면 바로 앞에 붙여넣습니다. 되돌리기 가능.
- 웅크리고 터치 메뉴: 90° 단위 회전, 좌우/앞뒤 뒤집기, 공기 붙여넣지 않기, 비우기. 웅크리고 부수기 = 90° 회전.
- 클립보드는 메모리에만 있어서 서버를 다시 켜면 비워집니다(오래 둘 것은 에셋으로 저장).

## 입력 폼

8Crafter 폼처럼 간단하게 만들었습니다. 모든 블록 입력은

- **가져올 곳**: 블록 피커로 고른 블록 / 직접 입력 / 손에 든 블록 / 바라보는 블록 / 핫바 블록 섞기 / 저장한 팔레트
- **블록 ID / 패턴**: `stone`, `50%stone,andesite`, `oak_slab`, `oak_stairs[weirdo_direction=2]`, `#turb[10][red_wool,blue_wool]` …
- **직접 입력을 새 팔레트로 저장** 토글

각도는 슬라이더로 몇 도인지 보면서 고르고, 아르세온의 플래그(-n, -d, -p …)는 설명이 붙은 토글입니다.
마지막에 입력한 값은 도구마다 기억됩니다.

**반블록(슬랩) 패턴**이면 도로·아치·지붕·점선·곡면/면 채우기·지형 생성·글자가 아르세온처럼 반 칸 단위로 다듬고,
`snow_layer` 패턴이면 눈 층, `water` 이면 물 높이로 다듬습니다.

### 차선 도로

곡선 점을 따라 차선이 그려진 도로를 한 번에 깝니다(직선 도로는 곡선 점 2개). 좌우는 **첫 점 → 마지막 점으로 갈 때** 기준입니다.
기본값은 노란 가장자리선 | 차로 3칸 × 3 (사이 흰 점선) | 노란 중앙선 | 차로 3칸 × 3 | 노란 가장자리선 = **폭 25칸**,
흰 점선은 **4칸 칠하고 4칸 띄우기**, 옆 점선끼리 엇갈림입니다.

- **선은 어느 각도에서도 1칸 두께**입니다(45°, 30°, 곡선 모두). 점선도 대각선에서 4칸씩 셉니다.
- **왼쪽 차로 수 / 오른쪽 차로 수**를 따로 정합니다(예: 왼쪽 3, 오른쪽 4). 한쪽을 0으로 하면 일방통행 도로.
- 중앙: 노란 실선 1줄 / 2줄 / 점선 / 없음(일방통행, 흰 점선) / **1차선 도로**(차로 하나, 중앙선 없음)
- **중앙분리대 폭**(0 = 없음): **노란 테두리 + 체크무늬(지그재그)** (기본, 폭 4 추천 = 테두리 2줄 + 체크 2줄, 도로 처음부터 끝까지) / 노란색으로 꽉 채우기 / 노란 테두리 + 빗금(안전지대) / 테두리 선만
- **유턴 구간**: 길이(칸)와 위치(도로 끝 쪽 / 시작 쪽 / 양쪽 끝)를 정하면 그 구간은 중앙선·분리대 대신 흰 유턴선
  (짧은 점선 1칸-1칸 또는 흰 실선)이 그려집니다.
- **차로 폭** = 흰 선 사이 바닥 칸 수(1~10), **갓길** = 노란 가장자리선 바깥 바닥 칸 수(0~10)
- **고급 옵션**을 켜면 다음 화면에서 차로 수에 맞춰 **차로마다 폭**과 **차로 사이 선마다** 고릅니다:
  차선바꿈(흰 점선) / 유지(흰 실선, 차선 변경 금지) / 선 없음. 1차로 = 중앙선 쪽 차로입니다.
  예) 오른쪽 3차로를 1·2 사이 "유지", 2·3 사이 "차선바꿈"
- 바닥·중앙선(분리대)·차선(유턴선)·가장자리선 블록을 각각 고를 수 있습니다(블록 피커로 고른 블록도 됨).
-  점선 길이·간격, 엇갈림, 도로 두께, 아래로 땅까지 채우기, 도로 위 비우기, 곡선을 덜 휘게
- 곡선 점은 도로가 깔릴 높이의 블록(지면)에 찍으세요. 그 높이가 도로 윗면이 됩니다.

#### 커스텀 차선 (에셋처럼)

1. 원하는 차선 모양으로 도로를 **직선으로 한 토막** 직접 만듭니다(블록·색 자유, 여러 층도 됨).
2. 영역을 **도로 전체 폭 × 점선 한 주기 길이**(예: 4칸 칠하고 4칸 띄우면 8칸)로 잡습니다.
3. 도로가 뻗는 방향을 바라보고 곡선 도구 > **커스텀 차선 저장 · 지우기** > 이름을 넣어 저장합니다.
4. **차선 도로** > 차선 모양에서 `커스텀: 이름`을 고르면, 그 토막이 곡선을 따라 반복해서 깔립니다.
   - 바닥에 가장 많은 블록 = 바닥, 그 외의 블록이 있는 줄 = 선으로 보고, 선은 대각선·곡선에서도 1칸 두께로 그립니다.
   - 여러 층으로 저장하면 그 두께로 깔립니다. 커스텀 차선은 월드에 저장돼 모든 플레이어가 씁니다(폭·길이 64칸까지).

### 철도

곡선 점을 **선로 바닥(자갈) 높이의 블록**에 찍고 곡선 도구 > **철도**.

**선로**
- 기본 선로(직접 지으신 양식): 자갈 바닥 위에 **돌 반블록 섞기**(안산암 60% · 돌 20% · 조약돌 15% · 응회암 5%, 모두 아래 반블록),
  **진흙 벽돌(통블록) 침목**(1칸 놓고 1칸 띄움, **양 끝은 진흙 벽돌 계단**으로 레일 쪽이 높게), **모루 레일**(모루와 모루 사이 2칸).
- 침목은 한 개씩 **선로에 수직인 1칸 선**으로 놓습니다. 간격은 격자 칸 수로 세서 대각선(45°)에서도 일정하게 반복되고,
  곡선에서는 그 자리의 방향에 맞춰 돌아갑니다. 끝 계단도 그 방향에서 가장 가까운 쪽을 보고 레일 쪽으로 올라갑니다.
- **선로 수**는 첫 화면에서 1개(단선) / 2개(복선, 기본) / 3개 … 8개.
- "기본 선로 고급 설정"을 켜면 **레일(모루) 사이 칸 수**, 레일 바깥 침목 길이, 침목 바깥 자갈, 선로 사이 자갈, 침목 두께·간격,
  자갈 / **자갈 위 반블록 비율** / **침목 비율** / **침목 끝 계단** / 레일 블록을 바꿀 수 있습니다. 비율은 `60%andesite_slab,40%tuff_slab` 처럼 씁니다.
- **직접 만든 선로**: 선로를 직선으로 한 토막 지은 뒤, 전체 폭 × 침목 한 주기(예: 2칸) × 자갈부터 레일까지 높이를 영역으로 잡고,
  선로 방향을 바라보고 **철도 선로 저장 · 지우기**로 저장 → 철도 > 선로 모양에서 고릅니다.
- 레일처럼 끝까지 같은 블록이 이어지는 줄은 대각선·곡선에서도 **1칸 두께**로, 침목은 진행 방향에 수직으로 반복합니다.
  **모루·계단·반블록처럼 방향이 있는 블록은 선로가 꺾이면 같이 돌아갑니다**(가장 가까운 90°).
- 선로 높이의 풀·블록 비우기(기본 켬), 선로 아래 땅까지 채우기.

**전신주**
- **기본 전신주**(기본값): 직접 지으신 구조물(`mystructure:1`·`2`·`3`)을 분석한 규칙으로 **레일 위치에 맞춰 조립**합니다.
  기둥은 바깥 레일에서 5칸 밖(바닥이 더 넓으면 더 밖), 보는 6칸마다 계단이 들어가는 2단 트러스, 레일마다 모루 + 깔때기(전차선),
  기둥 꼭대기 무거운 코어(급전선). 1·2·3선은 원래 구조물과 블록 하나까지 같고(테스트로 확인), **5선·6선 이상, 레일 사이 칸 수나
  선로 사이 자갈 폭을 바꿔도** 레일 위에 맞춰 지어집니다.
- **기본 기둥만**: `mystructure:야` 기둥을 전신주 기둥 자리 양쪽에 세우고 급전선만 겁니다.
- 전선 버튼마다 위(매단 버튼) 또는 아래(눕힌 버튼)에 **보이지 않는 방벽**을 받쳐서 떨어지지 않게 합니다(직접 지으신 방식, 끌 수 있음).
- 원본 다시 뽑기: `python3 tools/arceon_dlc/extract_poles.py <월드>/db` → `lib/pole_data.js`.
- **커스텀 전신주**: 직접 지은 전신주를 에셋으로 저장해서 고를 수 있습니다.
  1. 전신주를 짓고(아무 모양), **전선이 걸릴 자리마다 버튼**을 달아 둡니다.
  2. 영역으로 전신주를 잡고, **선로 가운데 바닥 블록을 바라보면서 선로 방향을 보고** 에셋 도구로 저장(부수기 → 이름).
  3. 철도 > 전신주에서 "커스텀 (에셋): 이름"을 고릅니다.
- **전신주 간격 정하는 방법**
  - 일정 간격 + 곡선에서는 자동으로 촘촘하게(기본): 직선은 간격(기본 20칸) 그대로, 곡선에서는 두 전신주 사이 전선이 선로 가운데서
    정한 칸 수(기본 1칸)보다 벗어나지 않을 때까지 간격을 줄입니다(가장 좁게 기본 8칸).
  - 일정 간격 그대로 / 개수로 정하기(처음부터 끝까지 고르게) / 간격 직접 적기(`20, 30` → 20·30 반복).
  - 첫 전신주 위치, 끝점에도 세우기.
- 전신주 방향: **선로 각도 그대로**(기본, 블록을 이웃 쪽 중간점까지 같이 옮겨서 꺾여도 끊기지 않고, 1칸 두께 부분은 1칸 그대로) /
  **90° 단위로만**(모양 100% 그대로, 대각선 선로에서는 비스듬히 가로지름).

**전선**
- **전차선 높이**: 기본 전신주는 "전차선 높이 (레일 위 칸 수)"로 전신주 전체가 늘거나 줄어듭니다(기본 5칸, 트러스 안에서는 트러스 높이까지).
- 전신주 안의 **버튼 위치를 자동으로 인식**해서, 다음 전신주의 같은 버튼까지 **처지는 곡선**을 따라 버튼(눕힌 상태)을 겁니다.
  전선 블록(기본 윤나는 흑암 버튼), 버튼 간격(기본 2칸), 처짐(기본 1칸)을 바꿀 수 있습니다.
- 전신주 없이 전선만: "가로:높이"를 쉼표로(예: `-4:7, 4:7`, 가로는 선로 가운데 기준 오른쪽 +).

**교량 (선로를 다리 위에, 숨김 기능)** — 곡선 점 높이가 선로 바닥 높이, 교각은 경간마다(끝 포함) 땅까지 내려갑니다.

| 종류 | 이름 | 디테일 |
|---|---|---|
| 철교 1 | 강판형교 (야마노테선 고가 양식) | 바깥 거더 보강재 2칸 간격 + 리벳(버튼) 줄, 그레이팅 보도 + 삼각 브래킷, 케이블 트로프 덮개, 야마노테선 방호벽(구리 격자 3단 + 볼트 머리, 위 단에 체인, 호퍼 갓돌 + 철창 울타리), 레일마다 거더, 가로보·대경구·하부 횡구, 자갈막이, 강재 교각(위로 벌어지는 기둥머리 + 보강 리브 + 이음 띠·볼트 + 박스 가로보 + 받침 슈 + 계단식 돌 받침 + 앵커 볼트) |

- **재질**: 교각·하부는 한 블록으로 칠하지 않고 돌·석재 벽돌·응회암·안산암·금 간/이끼 낀 석재 벽돌을 섞고, 땅에 닿는 기초는
  이끼 낀 조약돌·이끼 낀 석재 벽돌 위주로 더 축축하게. 교각마다 섞임이 달라 같은 모양이 반복되지 않습니다.
- **트러스는 경간마다 직선**: 곡선이면 교각과 교각을 잇는 직선(현)으로 한 경간씩 놓고, 교각에서 각도를 꺾어 곡선을 따라갑니다
  (교각은 앞뒤 경간 방향의 중간으로 돌아감). 선로는 그대로 곡선. `docs/img/bridges_truss_curve.png`, 강판형교: `docs/img/bridge_plate_yamanote.png`
- **트러스 위 전신주**: 워렌 트러스는 고른 전신주가 **통째로 수직재 자리(경간마다 14·42칸)에** 서고, 경간 방향에 맞춰 돕니다.
  사각 트러스는 기둥 없이 수직재 사이에 보만 겁니다(15칸마다).
- **조명**: 모든 교량에 자연스럽게 불이 들어갑니다. 난간 위에 12칸마다 랜턴, 교량 아래 가운데에 매달린 랜턴, 트러스 포털 아래 매단 랜턴,
  그리고 보이지 않는 빛 블록(교량 아래, 보도 쪽)으로 밤에도 은은하게 밝습니다.
- **박스교 재질**: 고가 박스교·세그먼트 박스교는 매끄러운 돌 없이 거친 안산암(+ 돌·응회암·조약돌)으로.
- **가드벽·난간은 레일보다 2칸 높게** 서서, 선로가 방호벽 사이로 낮게 지나갑니다(판형교는 보도 그레이팅이 자갈 높이, 난간 2칸 + 손스침).
- **슬래브교 기둥 간격**: 고급 설정 화면에서 조절(기본 6칸).
- **선로 바닥 채우기**: 선로 바닥과 난간·보도 사이 빈 칸은 선로와 같은 자갈 + 돌 반블록으로 채웁니다.
- **안전망 (땅 위)**: 교량이 없을 때 선로 양옆(바닥 1칸 밖)에 안전망을 칩니다. 철망(철창 + 4칸마다 안산암 담장 기둥 + 반블록 갓) 또는
  격자(구리 격자 + 위에 철창, 4칸마다 구리 전구 조명). 높이 2~4칸, 곡선·대각선에서도 이어지게 다듬습니다.
- **트러스교는 무도상**: 자갈·돌 반블록 없이 철판 바닥 위에 침목과 레일만 놓습니다.
- **철교 색**: 녹색 도장(풍화 구리) / 청록(녹슨 구리) / 갈색(산화 구리) / 회색 도장.
- **경간**: 0이면 종류별 기본값. 트러스·아치는 모양 때문에 고정(트러스는 전체 길이를 경간 수로 고르게 나눔).
- 대각선·곡선 정리: 모서리로만 이어진 1칸 부재 메우기, 철창·담장 잇기, 판 없는 볼트 돌리기/지우기.

### 선로 기록 · 이어 깔기 · 분기 (숨김 기능)

숨김 기능이 열린 플레이어가 **철도 도구**로 선로를 깔면, 그 선로가 월드에 기록됩니다.

- **선로 끝은 블록 한 칸**(빨간 콘크리트): 이어지지 않은 끝마다 선로 가운데 바로 바깥에 한 칸이 놓입니다.
- **이어 깔기**: 첫 곡선 점(또는 마지막 점)을 그 끝 블록(또는 끝 근처 3칸)에 찍으면 그 끝에서 같은 방향으로 매끄럽게 이어지고,
  끝 블록은 치워집니다. 복선 끝에서 단선으로 이으면 찍은 쪽 선로에 붙습니다.
- **분기 / 합류**: 첫 점을 깔린 선로의 옆(몸통)에 찍고 → 갈 곳을 찍으면 그 자리에서 1:N 분기기로 갈라집니다.
  마지막 점을 선로 옆에 찍으면 분기기로 합류합니다. 텅레일 옆에 선로전환기, 크로싱에 가드레일이 붙고,
  나중에 깐 선로가 먼저 깔린 레일을 덮지 않습니다. (예: 중간 터치 → 꺾일 곳 터치 → 새 선로 끝 터치)
- 교량·전신주·전선 설정은 평소 철도 도구 그대로 적용됩니다.

### 배선 도구 (숨김 기능)

`arc:yard_tool` 아이템(숨김 기능이 열렸을 때 도구 아이템 받기에 나옴). 프레임처럼 **선을 여러 개 그려 저장해 두고**, 한꺼번에
철도 설정(선로·교량·전신주·전선)으로 깝니다. 끝끼리 이어지고, 아직 안 깐 저장한 선에서도 이어 붙이거나 갈라질 수 있습니다.

| 동작 | 하는 일 |
|---|---|
| 선로 끝 블록 / 저장한 선의 끝 터치 | 이 끝에서 시작 (이미 점이 있으면 이 끝까지 그리고 선 저장) |
| 선로 옆(몸통) / 저장한 선의 중간 터치 | 여기서 분기 시작 (이미 점이 있으면 여기로 합류하고 선 저장) |
| 빈 곳 터치 | 지나갈 점 추가 |
| 부수기 | 마지막 점 취소 (점이 없으면 시작, 그다음은 마지막 저장한 선) |
| 웅크리고 부수기 | 지금 그리는 선 저장 (다음 선 시작) |
| 웅크리고 터치 | 메뉴: 저장한 선 깔기, 선 저장, 선로 연결, 기록된 선로, 분기기 번수, 모두 지우기 |

- **깔기**: 철도 도구와 같은 설정 창이 나오고, 저장한 선을 순서대로 깝니다. 먼저 깐 선에서 이어지거나 갈라지는 선은 그 실제 선로에 붙습니다.
- **선로 연결 (건넘선 · 시서스)**: 메뉴에서 고른 뒤 선로 하나(복선이면 그 선)를 터치하고, 건너갈 선로를 터치합니다.
  두 선로 사이에 양 끝이 선로와 나란한 매끄러운 S자(1:N보다 급하지 않게)로 건넘선을 깔고, 양쪽에 분기기 설비가 붙습니다.
  시서스는 같은 구간에 반대 방향 건넘선을 하나 더 깔아 X자가 됩니다. 두 번째 터치 지점까지가 건넘선 길이(너무 가까우면 더 길게).
- 기록: 월드에 선로마다 중심선(1칸 간격), 선로별 위치, 두 끝(열림/연결)을 저장. 메뉴에서 기록 지우기(블록은 그대로).
  되돌리기를 해도 기록은 남으니, 필요하면 기록 지우기를 쓰세요.
- 미리보기(위에서 본 모습): `docs/img/yard_connect.png` — 복선에 건넘선·시서스, 옆으로 분기, 끝에서 단선으로 이어 깔기.

### 자유 회전

- **좌우 회전 Y / 앞뒤 기울기 X / 옆 기울기 Z** 슬라이더(−180°~180°, 1° 단위)
- **제자리 회전**(원래 자리는 비움, 중심 = 영역 중심 또는 내가 선 칸) 또는 **돌린 복사본을 내 위치에 놓기**
- **월드는 그대로 두고 결과만 클립보드에 저장**: 클립보드 도구로 놓일 자리를 보면서 원하는 곳에 붙여넣기
- 계단·원목·문·표지판 등 방향이 있는 블록도 같이 돌아갑니다. 구멍 없이 채워집니다.

### 브러시 (메뉴 > 브러시)

**손에 든 아이템**(예: 막대기)에 브러시를 붙이고, 그 아이템으로 터치하면 바라보는 블록(300칸)에 적용됩니다.

바위, 큐브, 가시, 지형 다듬기(메우기/다듬기/들어올리기/녹이기/걷어내기), 회전 복제(영역 사용), 덩굴, 작물.
크기 범위(`[min],[max]`)는 최소·최대 두 칸으로 입력합니다.

### 에셋

1. 영역을 잡고 에셋 도구로 **부수기** → 이름을 넣어 저장. 이때 **바라보는 블록이 기준점**이 됩니다(-c 가운데, -f 바닥).
2. 에셋 도구로 웅크리고 터치 > 놓을 에셋 고르기: 이름 여러 개(쉼표) = 놓을 때마다 무작위, 회전(바라보는 방향/무작위/없음), 뒤집기.
3. 에셋 도구로 **터치**하면 놓입니다. 되돌리기 가능.

에셋은 월드의 구조물(`arc_asset:<이름>`)로 저장되어 서버를 다시 켜도 남습니다.

### 마스크 · 패턴

설정 > 전역 마스크(끌어 늘리기·채우기·브러시에 적용)와 패턴 채우기의 마스크 칸에서 씁니다.

- 마스크: `stone,dirt` `!air` `#existing` `#solid` `#arcangle[0][30][2]` `#prox[wool][5]` `#prox3D[..][..]`
  `#above[..][..]` `#below[..][..]` `y[45][50]` `#type[oak]` `#cc[red]` `#ambient` `#ygradient[10][20]`
  `#noise[시드][확대][비율]` `#turbulence` `#electric` `#crack` `#cell` `#voronoi` `#fractal` — 공백으로 여러 개 = 모두 만족
- 패턴: `50%stone,andesite` `oak_slab[top]` `#type[quartz]` `#cc[lime]` `#invert` `#blend` `#dp[0~5]`
  `#turb[크기][블록목록][시드]` `#elec` `#arcvor` `#frac` `#cell[크기][블록목록][지터]`

블록 이름은 베드락 ID입니다. 자주 쓰는 자바 이름(`bricks`, `end_stone_bricks`, `oak_door` …)도 알아듣습니다.

## 알아둘 점

- 큰 작업은 한 틱에 수천 블록씩 나눠 처리하고, 한 번에 최대 200만 블록까지 바꿉니다.
- **로드 안 된 먼 곳**: 설정 > "로드 안 된 먼 곳도 불러와서 설치"(기본 켜짐)이면 작업을 청크 묶음으로 나눠
  틱킹 영역으로 잠깐 불러와서 설치하고 바로 놓아줍니다(되돌리기도 같음). 도구가 지형을 읽는 영역(강·지형 생성 등)도 미리 불러옵니다.
  끄면 예전처럼 로드 안 된 곳은 건너뛰고 몇 블록을 건너뛰었는지 알려 줍니다.
- 되돌리기 기록과 클립보드는 메모리에 있어서 서버를 다시 켜면 사라집니다. 점·영역·프레임·블록 피커·브러시·설정은 저장됩니다.
- 표지판 글자, 상자 내용물 같은 블록 엔티티 데이터는 복사·회전되지 않습니다(블록 모양과 상태만).
- 색 바꾸기: 현수막·침대 색은 베드락에서 스크립트로 바꿀 수 없어 건너뜁니다. 내용물이 든 셜커 상자도 건너뜁니다.
- 종류 바꾸기: 표지판은 글자가 사라지므로 바꾸지 않습니다.
- 텍스트 글꼴은 아르세온에 들어 있던 11종을 미리 비트맵으로 변환했습니다. 아르세온의 unicode 글꼴(MS Mincho)에는
  **한글이 없어서** 한글은 WenQuanYi Zen Hei(GPL, 글꼴 포함 예외)로 그렸습니다. 작은 크기(14 미만)는 자바보다 거칠 수 있습니다.
- 지형 생성 노이즈는 아르세온의 FastNoise를 그대로 옮겨, 같은 시드면 자바와 같은 값이 나옵니다.
- 아르세온과 다르게 고친 점: 축 회전 복제의 뒤집힌 복사·1칸 밀림·시작 각도 무시 버그를 바로잡았고,
  지형 생성은 열마다 한 번만 쌓습니다(자바에서 -e를 쓰면 겹쳐 쌓이던 문제).
- 발광 이끼를 덩굴 브러시로 쓸 때 방향은 아직 게임에서 확인하지 못했습니다.
