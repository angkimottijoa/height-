# 아르세온 DLC (8Crafter's Server Utilities 확장)

`dist/ArceonDLC.mcaddon` — 행동 팩 1개(리소스 팩 없음). MCBE **1.26.40 이상**.

Java 플러그인 **Arceon 0.5.6**(Arcaniax)의 건축 도구를 뜯어서 베드락 스크립트로 옮긴 애드온입니다.
서버에 이미 들어가 있는 **8Crafter's Server Utilities & Debug Sticks**와 같이 쓰는 확장(DLC)으로 만들었고,
그 팩의 선택 도구로 찍은 pos1/pos2를 그대로 따라옵니다. 8Crafter 팩이 없어도 단독으로 동작합니다.

그림자(Shadow)·로프(Rope)·실험적 도구(Wax, FixConnect, WFC)는 요청대로 넣지 않았습니다.

## 시작하기

1. 월드(서버)에 `ArceonDLC.mcaddon`의 행동 팩을 추가합니다. 실험적 기능은 필요 없습니다.
2. 관리자(OP)이거나 `arceon` 태그가 있어야 합니다. (`/tag <이름> add arceon`)
3. `/arc:tools` 로 **도구 아이템 7개**를 받습니다.

| 명령어 | 내용 |
|---|---|
| `/arc:tools` | 도구 아이템 7개 받기 |
| `/arc:menu` | 전체 메뉴 |
| `/arc:wand` | 영역 지팡이·곡선 지팡이만 받기 |
| `/arc:undo` / `/arc:redo` | 되돌리기 / 다시 하기 (플레이어마다 15번) |

## 도구 아이템 (모바일 기준 조작)

**터치** = 블록을 가볍게 톡 (PC: 우클릭), **부수기** = 꾹 눌러 부수기 (PC: 좌클릭).
도구를 들고 **웅크리고 터치**하면 그 도구의 메뉴가 열립니다. 도구로 블록을 부숴도 블록은 부서지지 않습니다.

| 아이템 | 터치 | 부수기 | 웅크리고 부수기 |
|---|---|---|---|
| **영역 지팡이** (블레이즈 막대) | 1번 지점 | 2번 지점 | |
| **곡선 지팡이** (브리즈 막대) | 곡선 점 추가 | 마지막 점 취소 | 점 모두 지우기 |
| **프레임 피커** (자수정 조각) | 지금 프레임에 점 추가 | 마지막 점 취소 | **프레임 저장** (다음 점부터 새 프레임) |
| **블록 피커** (망원경) | 그 블록 저장 (방향 등 상태 포함) | 마지막 블록 빼기 | |
| **클립보드 도구** (종이) | 붙여넣기 | 선택 영역 복사 | 90° 회전 |
| **에셋 도구** (메아리 조각) | 고른 에셋 놓기 | 선택 영역을 에셋으로 저장 | |
| **지형 도구** (빈 지도) | 지형 메뉴 (지형 생성, 눈 덮기) | | |

- 터치는 블록을 바라보기만 해도 300칸 멀리까지 됩니다.
- 입자: 영역 지팡이는 영역 테두리, 곡선 지팡이는 곡선 점과 곡선(+영역 테두리)을 보여 줍니다.
- 영역 지팡이·곡선 지팡이 메뉴(웅크리고 터치)에 곡선 도구·모양 만들기·변형·채우기·글자 쓰기·브러시·설정이 있습니다.
- 영역과 곡선 점은 **따로 저장**됩니다. 곡선 지팡이로 부숴도 영역은 그대로입니다.
- 꾹 누르고 있어도 **한 번만** 처리됩니다(손을 뗐다가 다시 눌러야 다음 동작).
- 도구를 들고 있으면 입자로 보입니다: 영역 테두리(엔드 막대), 곡선 점(초록)과 곡선(불꽃), 프레임(파란 불꽃, 그리는 중인 프레임은 초록)과 **프레임끼리 이어지는 레일**(불꽃 — 채울 때와 같은 계산이라 이대로 이어짐),
  클립보드는 **바라보는 곳에 붙여넣으면 차지할 영역**을 불꽃 테두리로 보여 줍니다.
- **8Crafter 선택 도구**로 찍은 1번·2번 지점도 자동으로 따라옵니다. (그 팩의 저장값은 다른 팩이 읽을 수 없어서,
  선택 도구를 쓸 때마다 같은 방식으로 따라 기록합니다. 8Crafter의 `\pos1` 같은 명령어로 지정한 값은 따라오지 않습니다.)
- 곡선 도구에 곡선 점이 없으면 1번 → 2번 지점을 잇는 선을 씁니다.

### 프레임 피커 — 곡면 채우기 / 면 채우기

프레임은 도형 하나(점 여러 개)입니다. 점을 터치로 찍고, 웅크리고 부수기로 저장하면 다음 점부터 새 프레임이 됩니다.
웅크리고 터치 > **채우는 방식 바꾸기**로 둘 중 하나를 고르고 **실행**합니다.

- **곡면 채우기** (아르세온 로프트): 프레임과 프레임 사이를 매끄러운 곡면으로 잇습니다. 프레임이 1개면 그 도형을 평면으로 채웁니다.
- **면 채우기**: 평평한 면으로 채웁니다. 프레임 1개 = 도형 안 채우기(오목한 도형도 됨), 여러 개 = 프레임 사이를 평면으로 잇기.
  처음·마지막 프레임 막기, 끝 점과 첫 점도 잇기(통 모양), 테두리 선만 옵션.

### 블록 피커

블록 피커로 블록을 터치하면 그 블록이 **상태 그대로** 저장됩니다(최대 27개). 모든 도구의 블록 입력에서
"블록 피커로 고른 블록"이 기본으로 선택되어 바로 씁니다. 웅크리고 터치하면 목록이 나오고, 켠 블록만 섞어 쓰거나
팔레트로 저장하거나 목록을 비울 수 있습니다(하나도 안 켜면 전부 섞어 씀).

### 클립보드

- 클립보드 도구로 **부수기** = 선택 영역 복사. **자유 회전**과 **크기 조절**에서 "월드는 그대로 두고 결과만 클립보드에 저장"을 켜면
  돌리거나 키운 결과가 클립보드로 들어옵니다(원본은 그대로).
- 클립보드 도구를 들면 바라보는 곳에 놓일 자리가 테두리로 보이고, **터치**하면 터치한 면 바로 앞에 붙여넣습니다. 되돌리기 가능.
- 웅크리고 터치 메뉴: 90° 단위 회전, 좌우/앞뒤 뒤집기, 공기 붙여넣지 않기, 비우기. 웅크리고 부수기 = 90° 회전.
- 클립보드는 메모리에만 있어서 서버를 다시 켜면 비워집니다(오래 둘 것은 에셋으로 저장).

## 입력 폼

8Crafter 폼처럼 간단하게 만들었습니다. 모든 블록 입력은

- **가져올 곳**: 블록 피커로 고른 블록 / 직접 입력 / 손에 든 블록 / 바라보는 블록 / 핫바 블록 섞기 / 저장한 팔레트
- **블록 ID / 패턴**: `stone`, `50%stone,andesite`, `oak_slab`, `oak_stairs[weirdo_direction=2]`, `#turb[10][red_wool,blue_wool]` …
- **직접 입력을 새 팔레트로 저장** 토글

각도는 슬라이더로 몇 도인지 보면서 고르고, 아르세온의 플래그(-n, -d, -p …)는 설명이 붙은 토글입니다.
마지막에 입력한 값은 도구마다 기억됩니다.

**반블록(슬랩) 패턴**이면 도로·아치·지붕·점선·곡면/면 채우기·지형 생성·글자가 아르세온처럼 반 칸 단위로 다듬고,
`snow_layer` 패턴이면 눈 층, `water` 이면 물 높이로 다듬습니다.

### 차선 도로

곡선 점(또는 1번 → 2번 지점 직선)을 따라 차선이 그려진 도로를 한 번에 깝니다. 좌우는 **첫 점 → 마지막 점으로 갈 때** 기준입니다.
기본값은 노란 가장자리선 | 차로 3칸 × 3 (사이 흰 점선) | 노란 중앙선 | 차로 3칸 × 3 | 노란 가장자리선 = **폭 25칸**,
흰 점선은 **4칸 칠하고 4칸 띄우기**, 옆 점선끼리 엇갈림입니다.

- **선은 어느 각도에서도 1칸 두께**입니다(45°, 30°, 곡선 모두). 점선도 대각선에서 4칸씩 셉니다.
- **왼쪽 차로 수 / 오른쪽 차로 수**를 따로 정합니다(예: 왼쪽 3, 오른쪽 4). 한쪽을 0으로 하면 일방통행 도로.
- 중앙: 노란 실선 1줄 / 2줄 / 점선 / 없음(일방통행, 흰 점선)
- **중앙분리대 폭**(0 = 없음): 노란색으로 꽉 채우기 / 노란 테두리 + 빗금(안전지대) / 테두리 선만
- **유턴 구간**: 길이(칸)와 위치(도로 끝 쪽 / 시작 쪽 / 양쪽 끝)를 정하면 그 구간은 중앙선·분리대 대신 흰 유턴선
  (짧은 점선 1칸-1칸 또는 흰 실선)이 그려집니다.
- 바닥·중앙선(분리대)·차선(유턴선)·가장자리선 블록을 각각 고를 수 있습니다(블록 피커로 고른 블록도 됨).
- 차로 폭(1~10), 점선 길이·간격, 엇갈림, 도로 두께, 아래로 땅까지 채우기, 도로 위 비우기, 곡선을 덜 휘게
- 곡선 점은 도로가 깔릴 높이의 블록(지면)에 찍으세요. 그 높이가 도로 윗면이 됩니다.

### 자유 회전

- **좌우 회전 Y / 앞뒤 기울기 X / 옆 기울기 Z** 슬라이더(−180°~180°, 1° 단위)
- **제자리 회전**(원래 자리는 비움, 중심 = 영역 중심 또는 내가 선 칸) 또는 **돌린 복사본을 내 위치에 놓기**
- **월드는 그대로 두고 결과만 클립보드에 저장**: 클립보드 도구로 놓일 자리를 보면서 원하는 곳에 붙여넣기
- 계단·원목·문·표지판 등 방향이 있는 블록도 같이 돌아갑니다. 구멍 없이 채워집니다.

### 브러시 (메뉴 > 브러시)

**손에 든 아이템**(예: 막대기)에 브러시를 붙이고, 그 아이템으로 터치하면 바라보는 블록(300칸)에 적용됩니다.

바위, 큐브, 가시, 지형 다듬기(메우기/다듬기/들어올리기/녹이기/걷어내기), 회전 복제(영역 사용), 덩굴, 작물.
크기 범위(`[min],[max]`)는 최소·최대 두 칸으로 입력합니다.

### 에셋

1. 영역을 잡고 에셋 도구로 **부수기** → 이름을 넣어 저장. 이때 **바라보는 블록이 기준점**이 됩니다(-c 가운데, -f 바닥).
2. 에셋 도구로 웅크리고 터치 > 놓을 에셋 고르기: 이름 여러 개(쉼표) = 놓을 때마다 무작위, 회전(바라보는 방향/무작위/없음), 뒤집기.
3. 에셋 도구로 **터치**하면 놓입니다. 되돌리기 가능.

에셋은 월드의 구조물(`arc_asset:<이름>`)로 저장되어 서버를 다시 켜도 남습니다.

### 마스크 · 패턴

설정 > 전역 마스크(끌어 늘리기·채우기·브러시에 적용)와 패턴 채우기의 마스크 칸에서 씁니다.

- 마스크: `stone,dirt` `!air` `#existing` `#solid` `#arcangle[0][30][2]` `#prox[wool][5]` `#prox3D[..][..]`
  `#above[..][..]` `#below[..][..]` `y[45][50]` `#type[oak]` `#cc[red]` `#ambient` `#ygradient[10][20]`
  `#noise[시드][확대][비율]` `#turbulence` `#electric` `#crack` `#cell` `#voronoi` `#fractal` — 공백으로 여러 개 = 모두 만족
- 패턴: `50%stone,andesite` `oak_slab[top]` `#type[quartz]` `#cc[lime]` `#invert` `#blend` `#dp[0~5]`
  `#turb[크기][블록목록][시드]` `#elec` `#arcvor` `#frac` `#cell[크기][블록목록][지터]`

블록 이름은 베드락 ID입니다. 자주 쓰는 자바 이름(`bricks`, `end_stone_bricks`, `oak_door` …)도 알아듣습니다.

## 알아둘 점

- 큰 작업은 한 틱에 수천 블록씩 나눠 처리합니다. 작업 범위가 로드돼 있어야 하고(로드 안 된 곳은 건너뜀),
  한 번에 최대 200만 블록까지 바꿉니다.
- 되돌리기 기록과 클립보드는 메모리에 있어서 서버를 다시 켜면 사라집니다. 점·영역·프레임·블록 피커·브러시·설정은 저장됩니다.
- 표지판 글자, 상자 내용물 같은 블록 엔티티 데이터는 복사·회전되지 않습니다(블록 모양과 상태만).
- 색 바꾸기: 현수막·침대 색은 베드락에서 스크립트로 바꿀 수 없어 건너뜁니다. 내용물이 든 셜커 상자도 건너뜁니다.
- 종류 바꾸기: 표지판은 글자가 사라지므로 바꾸지 않습니다.
- 텍스트 글꼴은 아르세온에 들어 있던 11종을 미리 비트맵으로 변환했습니다. 아르세온의 unicode 글꼴(MS Mincho)에는
  **한글이 없어서** 한글은 WenQuanYi Zen Hei(GPL, 글꼴 포함 예외)로 그렸습니다. 작은 크기(14 미만)는 자바보다 거칠 수 있습니다.
- 지형 생성 노이즈는 아르세온의 FastNoise를 그대로 옮겨, 같은 시드면 자바와 같은 값이 나옵니다.
- 아르세온과 다르게 고친 점: 축 회전 복제의 뒤집힌 복사·1칸 밀림·시작 각도 무시 버그를 바로잡았고,
  지형 생성은 열마다 한 번만 쌓습니다(자바에서 -e를 쓰면 겹쳐 쌓이던 문제).
- 발광 이끼를 덩굴 브러시로 쓸 때 방향은 아직 게임에서 확인하지 못했습니다.
